CATALOGUE FINS  (catalogue/)
----------------------------

These are cropped from the photographs above. Cropping counts as a
modification, which the CC BY-SA licences allow as long as it is stated.

    PPB001_01.jpg   side-on fin, cropped from Kirra_01.jpg   (Fromholtz, CC BY-SA 3.0)
    PPB002_01.jpg   left-hand fin, cropped from Pod_01.jpg   (Fromholtz, CC BY-SA 3.0)
    PPB003_01.jpg   right-hand fin, cropped from Pod_01.jpg  (Fromholtz, CC BY-SA 3.0)

The PPB reference numbers are made up for this project. They are NOT real
Burrunan dolphin catalogue IDs, and these are not identified individuals - they
are simply three different fins that happen to be photographed side on.


TEST SIGHTINGS  (sightings/)
----------------------------

    sighting_01.jpg   PPB002's fin, rotated, resized, brightened and blurred
    sighting_02.jpg   PPB001's fin, MIRRORED, rotated, resized and darkened
    sighting_03.jpg   the front-on fin cropped from Tambo_01.jpg (Menard, CC BY-SA 2.0 FR)

IMPORTANT, and worth saying out loud in the presentation: sightings 01 and 02
are not genuine re-sightings. There is no free set of photographs showing the
same wild Burrunan dolphin twice, so these were made by taking a catalogue fin
and changing it the way a second sighting would - different angle, distance,
lighting and sharpness. They prove the matching maths survives those changes.
They do not prove the program works on two genuinely separate photographs of
the same animal, because nothing here can prove that.

Sighting 03 is a real, untouched crop of a different dolphin, and the program
correctly refuses to match it.

For a proper test with genuinely re-sighted individuals, the Happywhale dataset
on Kaggle has over 15,000 individually identified marine mammals with several
photographs each. It needs a free Kaggle account to download:
    https://www.kaggle.com/competitions/happy-whale-and-dolphin


NOAA VALIDATION DATA
--------------------

The NOAA Beaufort, North Carolina photo dataset is used only to validate the
method on genuinely separate re-sightings of the same dolphin. It contains
bottlenose dolphins from North Carolina, not Burrunan dolphins from Gippsland,
so it must be described as stand-in validation data in the presentation.

    Source: NOAA Fisheries, InPort item 67547
    Licence/status: US government work, public domain
    Dataset page: https://www.fisheries.noaa.gov/inport/item/67547

Tagged, overlaid, obscured, and front-on fins were rejected so the program is
not accidentally identifying a tag or text.

The live display also includes this genuine re-sighting example, copied from
the archive while preserving the originals:

    catalogue/NOAA0423_01.jpg  <- 0423_PS304_10Aug2006_0487.JPG
    sightings/NOAA0423_01.jpg <- 0423_NES403_2013Jul10_AMG_N1_0398.JPG
    catalogue/NOAA0472_01.jpg  <- 0472_2007_Jun_27_20D0067.JPG
    sightings/NOAA0472_01.jpg <- 0472_SMR319_2018Jan17_AMG_0145.JPG
    sightings/NOAA0434_01.jpg <- 0434_2016Apr29_AMG_0056.JPG

The 0423 and 0472 catalogue/sighting pairs have matching NOAA IDs and are
separately taken photographs, not simulated edits. NOAA0434 appears only as a
sighting, so it must not be recognised; the program routes it to human review.
All comparisons use the fin silhouette and trailing-edge notch pattern only;
water and waves are excluded before comparison.
